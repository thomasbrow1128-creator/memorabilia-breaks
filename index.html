Everyone entered

Click any name to rename it, and Delete removes just that one name. Nothing here clears the whole board.

Entering a winner

Type a name into any box in the form buyer$item — for example alex$signed jersey. The part before the $ becomes the username, and the part after it becomes the item won. Both are written to the Winners page automatically with the date and time. The box itself shows only the buyer's name, so the boards stay readable.

A name with no $ is just an entry: it holds the box but logs no win, because no item was named. The winners log is append-only from the boards — only the Clear winners button removes anything from it.

Editing a name

Click the greyed box itself — clicking anywhere on a filled box opens the edit panel: the faded icon, the PURCHASER bar, or the gold name. Change the spelling and press Save, or press Remove to free that box for someone else. Cancel or Escape closes it without changing anything.

The grey is only a visual state — it never locks the box. As soon as the last name is removed the box returns to full colour with an open field.

Winners

Every item won, logged automatically when a box is filled as buyer$item. Type a tracking number straight onto the winner's line.

Items won

How this page fills up

Items won is filled automatically: every time a name is placed on a board as buyer$item, a line appears with the date, the time, the username and the item.

Tracking numbers are typed into the small box on each winner's own line — no separate list. Type the number and it saves as soon as you click away or press Enter.

Nothing on the boards can remove a line from this list — not Reset board, not Hide all, not removing or renaming a name. Only Clear winners empties it.

The customer ledger

This page is the shared ledger. Everything written here also appears, live, on the customer page: ledger.html — send customers that address and nothing else.

Customers type their username there and see their own items and tracking numbers. That page is read-only by the database's own rules: it holds no sign-in and cannot write, change or delete a single row, whoever is using it.

Because the ledger is open to anyone with the link, do not put anything private on a winner's line. The username, the item and the tracking number are all visible to whoever looks their own name up — and to anyone who guesses another name.
