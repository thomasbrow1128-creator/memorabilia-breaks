Entering a winner

Type a name into any box in the form buyer$item — for example alex$signed jersey. The part before the $ becomes the username, and the part after it becomes the item won. Both are written to the Winners page automatically with the date and time. The box itself shows only the buyer's name, so the boards stay readable.

A name with no $ is just an entry: it holds the box but logs no win, because no item was named. Taking a name off a box removes its logged win too.

Editing a name

Click the greyed box itself — clicking anywhere on a filled box opens the edit panel: the faded icon, the PURCHASER bar, or the gold name. Change the spelling and press Save, or press Remove to free that box for someone else. Cancel or Escape closes it without changing anything.

The grey is only a visual state — it never locks the box. As soon as the last name is removed the box returns to full colour with an open field.

How this page fills up

Nothing is entered here by hand. Every time a name is placed on a board as buyer$item, a line appears above with the date, the time, the username and the item.

Click a username or an item in the table to correct a spelling, or use Delete to remove just that one logged win. Clearing this page never changes the boards, and clearing the boards never wipes this history.
