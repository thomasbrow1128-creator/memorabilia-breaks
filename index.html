How to fix a name

On the board: every name sits in a greyed box as a small pill. Click the pill and a tiny editor opens right there — change the spelling and hit Save, or hit Remove to take that one person off. Nothing else on the board is touched.

In the list below: click any name to rename it in place, or use Delete on that row. Removing the last name from a box turns it back to full color so you can type a new one in.

Hide all is the only button that touches everything — and it offers an Undo straight afterwards if you hit it by mistake.

Adding a board: open boards.js and add one entry to the list. The tab, the grid, the heading and the counter all build themselves from it. Nothing else to change.
